# Screenshots

The README expects four files here, and renders broken images without them:

| file | what it should show |
|---|---|
| `screenshot-crt.png` | the dual-pane main window under Green CRT, ~880px wide |
| `theme-light.png` | the same window under Light |
| `theme-dark.png` | under Dark |
| `theme-crt.png` | under Green CRT, as a thumbnail beside the other two |

Keep the three theme shots the same size and framing as each other -- they sit
side by side in a table, and a mismatched crop reads as a different window
rather than as the same one wearing a different theme.
